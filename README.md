# AI 技術知識庫

以繁體中文整理 AI 技術概念的靜態網站，採用深藍黑色科技風格，使用原生 HTML、CSS 與 JavaScript 製作。

## 專案內容
- 大型語言模型（LLM）
- Prompt Engineering（提示工程）
- Retrieval-Augmented Generation（RAG）
- Vibe Coding

## 本機預覽
下載或複製專案後，直接以瀏覽器開啟根目錄的 `index.html` 即可。

## GitHub Pages 部署
1. 將專案所有檔案推送至 GitHub Repository。
2. 開啟 Repository 的 **Settings → Pages**。
3. 在 Build and deployment 選擇 **Deploy from a branch**。
4. Branch 選擇 `main`，資料夾選擇 `/ (root)`，按下 Save。
5. 等待部署完成，使用 GitHub Pages 顯示的網址瀏覽。

## AI 協作規範
開始修改前請先閱讀 [`AGENTS.md`](AGENTS.md)。新增文章時，請遵守文章格式、檔案命名、共用樣式與相對路徑規則。
