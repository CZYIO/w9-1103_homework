01 / FUNDAMENTALS

大型語言模型（LLM）

大型語言模型是一種以大量文字資料訓練，能理解並生成自然語言的人工智慧模型。

什麼是 LLM？

LLM 是 Large Language Model 的縮寫。模型透過訓練學習文字中的語言模式、上下文關係與知識表徵，因此能執行文字生成、摘要、翻譯、問答及程式輔助等任務。

基本運作概念

許多現代 LLM 使用 Transformer 架構，將輸入文字轉換成模型可處理的 token，再根據上下文預測後續 token，逐步產生回應。

重要觀念：模型產生的內容是根據訓練與輸入脈絡所生成，不代表每個回答都必然正確，仍需要查證。

常見應用

  • 自然語言問答與文字摘要
  • 程式碼解釋與除錯輔助
  • 文件整理、翻譯與內容草擬

延伸思考

使用 LLM 時，除了模型能力，也要注意資料隱私、資訊正確性與偏見等議題。
